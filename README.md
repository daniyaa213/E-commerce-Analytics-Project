
# E-Commerce Delivery Analytics Project

## Project Overview

This project focuses on analysing e-commerce delivery data using SQL and Microsoft Power BI. It aims to understand order patterns, delivery performance, customer behaviour and business trends through data analysis and visualisation.

## Project Objectives

- Analyse e-commerce order and delivery data.

- Identify important business trends and patterns.

- Examine delivery performance and delays.

- Use SQL queries for data extraction and analysis.

- Create an interactive dashboard using Power BI.

- Present meaningful insights to support business decisions.

## Tools and Technologies

- Microsoft SQL Server – Data querying and analysis.

- Microsoft Power BI – Data visualisation and dashboard creation.

- Excel – Dataset management.

## Project Work

*SQL Analysis:*

SQL queries are used to retrieve, filter and analyse the e-commerce data.

*Power BI Dashboard:*

An interactive dashboard is developed to represent key business information through charts, graphs and visualisations.

## Project Files

- DANIYAAA PROJECT.pbix – Power BI dashboard.

- Ecommerce_Delivery_Analytics.sql – SQL queries.

## Conclusion

This project demonstrates how SQL and Power BI can be used together to analyse e-commerce delivery data and present useful business insights.
